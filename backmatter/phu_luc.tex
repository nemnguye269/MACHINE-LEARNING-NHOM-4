\section*{Phụ lục 1. Mã nguồn chính của mô hình}

Phần mã nguồn dưới đây trình bày các bước cốt lõi: tiền xử lý, vector hóa TF-IDF và xây dựng mô hình KNN bằng Python (scikit-learn). Mã nguồn đầy đủ được lưu trữ trong kho GitHub của nhóm (xem Phụ lục 3).

\begin{enumerate}
    \item Tiền xử lý dữ liệu:
\end{enumerate}

{\small
\begin{verbatim}
import pandas as pd
import re, string
import nltk
from nltk.corpus import stopwords
from nltk.stem import PorterStemmer

fake = pd.read_csv("data/Fake.csv");  fake["label"] = 1
true = pd.read_csv("data/True.csv");  true["label"] = 0
data = pd.concat([fake, true]).sample(frac=1, random_state=42)
data["text"] = data["title"].fillna("") + " " + data["text"].fillna("")
data = data[["text", "label"]].dropna().drop_duplicates(subset="text")

stop_words = set(stopwords.words("english"))
stemmer = PorterStemmer()

def clean_text(s):
    s = re.sub(r"https?://\S+|www\.\S+", " ", s)
    s = re.sub(r"<.*?>", " ", s)
    s = s.lower().translate(str.maketrans("", "", string.punctuation))
    s = re.sub(r"\d+", " ", s)
    words = [w for w in s.split() if w not in stop_words]
    return " ".join(stemmer.stem(w) for w in words)
\end{verbatim}
}

\begin{enumerate}
    \setcounter{enumi}{1}
    \item Vector hóa TF-IDF và xây dựng mô hình KNN (mô hình chính):
\end{enumerate}

{\small
\begin{verbatim}
from sklearn.model_selection import train_test_split
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.neighbors import KNeighborsClassifier

X_train, X_test, y_train, y_test = train_test_split(
    data["text"], data["label"],
    test_size=0.25, random_state=42)

X_train = X_train.apply(clean_text)
X_test  = X_test.apply(clean_text)

# TF-IDF n-gram 1..2, toi da 50.000 dac trung, chuan hoa L2 (mac dinh)
tfidf = TfidfVectorizer(ngram_range=(1, 2), max_features=50000)
Xtr = tfidf.fit_transform(X_train)   # fit CHI tren tap huan luyen
Xte = tfidf.transform(X_test)

# KNN: k = 5, khoang cach cosine, trong so theo khoang cach
knn = KNeighborsClassifier(n_neighbors=5, metric="cosine",
                           weights="distance", algorithm="brute")
knn.fit(Xtr, y_train)                # voi KNN: chi la "ghi nho" du lieu
y_pred = knn.predict(Xte)
y_prob = knn.predict_proba(Xte)[:, 1]
\end{verbatim}
}

\begin{enumerate}
    \setcounter{enumi}{2}
    \item Đánh giá mô hình:
\end{enumerate}

{\small
\begin{verbatim}
from sklearn.metrics import (classification_report,
                             confusion_matrix, roc_auc_score)

print(classification_report(y_test, y_pred,
      target_names=["That", "Gia"]))
print(confusion_matrix(y_test, y_pred))
print("AUC =", roc_auc_score(y_test, y_prob))
\end{verbatim}
}

\section*{Phụ lục 4. Khai báo sử dụng công cụ AI}

Theo mục 2.3 của hướng dẫn học phần, nhóm khai báo phạm vi sử dụng công cụ AI như sau.

\begin{itemize}
    \item \textbf{Công cụ:} trợ lý AI dạng mô hình ngôn ngữ lớn, dùng qua giao diện hội thoại.
    \item \textbf{Mục đích:} giải thích lại lý thuyết (KNN, cosine similarity, TF-IDF, MultinomialNB) để đối chiếu với giáo trình; gợi ý cấu trúc hàm tiền xử lý và tham số vector hóa; gợi ý cách đọc thông báo lỗi; gợi ý bố cục bảng biểu, chú thích hình và cách diễn đạt một số đoạn văn; gợi ý bảng màu và bố cục giao diện Streamlit.
    \item \textbf{Phần nhóm tự thực hiện:} chọn dữ liệu và cách chia tập, quyết định cấu hình mô hình, chạy toàn bộ thí nghiệm trên máy của nhóm, kiểm tra chéo kết quả khi chạy lại, viết và sửa mã nguồn, đọc lại toàn bộ báo cáo.
    \item \textbf{Số liệu:} mọi con số trong báo cáo lấy từ các tệp trong \texttt{code/results/} do nhóm tự sinh ra; không có số liệu nào do AI tạo.
    \item \textbf{Kiểm chứng:} ba lệnh \texttt{train\_and\_evaluate.py}, \texttt{experiments\_representation.py} và \texttt{build\_reference.py} tái tạo lại toàn bộ bảng và biểu đồ của chương 3.
\end{itemize}

Khai báo đầy đủ được lưu tại tệp \texttt{AI\_USAGE.md} trong kho mã nguồn của nhóm.
